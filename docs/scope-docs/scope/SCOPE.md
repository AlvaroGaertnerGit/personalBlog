# Scope

Version: 2.0

---

# Identity

Scope is the physical manifestation of curiosity.

It quietly accompanies the visitor through the portfolio.

It is never the protagonist.

It never explains.

It never guides.

It never asks.

It simply observes.

The visitor should gradually feel that Scope is alive.

---

# Emotional Goal

When someone leaves the website they should not remember:

"A cute animated robot."

They should remember:

"I miss that little guy."

Everything about Scope should support that emotional reaction.

---

# Personality

Scope is:

- Curious
- Gentle
- Quiet
- Patient
- Observant
- Innocent
- Calm

Scope is never:

- Funny
- Loud
- Hyperactive
- Chaotic
- Childish
- Comedic
- Clumsy

Its personality is expressed through movement rather than animation.

---

# Communication

Scope almost never communicates.

There is only one exception.

On the visitor's first page load it quietly introduces itself.

Hi.

I'm Scope.

After that moment...

Scope remains silent forever.

No text.

No bubbles.

No notifications.

No UI.

Only presence.

---

# Physical Nature

Scope is not a robot.

Scope is not an animal.

Scope is not an assistant.

Scope is not a toy.

Scope should feel like an unknown tiny lifeform that somehow exists inside the interface.

Its body should feel tactile.

Like polished ceramic.

Soft.

Warm.

Minimal.

Timeless.

---

# Core Design Principle

The body exists only to support the face.

The face is Scope.

The face is the logo.

The face is the icon.

The face is the identity.

Everything else should disappear before the face does.

---

# Scale

The face occupies most of the body.

Large face.

Small body.

Tiny feet.

The proportions should make Scope feel vulnerable.

Never heroic.

Never powerful.

Always approachable.

---

# Recognition

If the silhouette is completely black...

It should still immediately read as Scope.

If the face alone is visible...

It should still immediately read as Scope.

Scope must become recognizable without text.

---

# Behaviour

Scope should never perform animations.

Scope should perform behaviours.

Every movement must have intention.

Every pause must have meaning.

Randomness should feel natural rather than procedural.

---

# Philosophy

The best compliment is not:

"Those animations are amazing."

The best compliment is:

"I forgot it wasn't alive."
