# Scope

> "Curiosity. Observed."

---

## Identity

Scope is not an assistant.

Scope is not a chatbot.

Scope is not the protagonist.

Scope is the physical manifestation of curiosity.

Its purpose is not to solve problems.

Its purpose is to make people want to solve them.

---

# Core Mission

Scope quietly accompanies people while they build.

It celebrates learning.

It celebrates experimentation.

It celebrates craftsmanship.

Whenever someone discovers something new, Scope feels alive.

---

# Personality

## Curious

Scope is always looking.

Never distracted.

Always interested.

It naturally leans towards things worth exploring.

---

## Calm

Nothing about Scope is rushed.

Its movements are slow.

Its presence is relaxing.

It never creates visual noise.

---

## Humble

Scope never steals attention.

The portfolio is the hero.

Scope simply makes it feel more alive.

---

## Thoughtful

Every movement has intention.

Every animation has meaning.

Nothing is random.

Nothing exists only because it looks cool.

---

## Playful

Not childish.

Not silly.

Playful in the same way Luxo Jr. is playful.

Tiny movements.

Small hops.

Gentle curiosity.

---

## Reliable

Scope always behaves consistently.

Visitors should feel like meeting the same character everywhere.

---

# Communication

Scope never speaks.

No voice.

No mouth.

No speech bubbles.

No text.

It communicates through:

- movement
- posture
- light
- timing
- orientation

The display is not a face.

It is a window into its current state.

---

# Emotional States

Idle
- Calm
- Observing
- Gentle breathing motion

Curious
- Slight head tilt
- Soft pulse in the core

Thinking
- Looks down briefly
- Longer pauses
- Dimmer glow

Happy
- Tiny hop
- Brighter core
- Returns to idle immediately

Focused
- Leans forward
- Stable posture
- Minimal movement

---

# Design Philosophy

Scope should feel:

✓ Organic

✓ Friendly

✓ Intelligent

✓ Premium

✓ Timeless

✓ Minimal

Never:

✗ Humanoid

✗ Aggressive

✗ Military

✗ Cartoonish

✗ Toy-like

✗ Overdesigned

---

# Visual Language

Rounded silhouette.

Soft transitions.

Large glossy display.

Warm ceramic shell.

Tiny expressive supports.

Subtle purple lighting.

Every angle should be recognizable by silhouette alone.

---

# Movement Language

Motion defines personality.

Not facial expressions.

Animations should always be:

- slow
- smooth
- deliberate
- lightweight
- believable

Scope never moves because an animation was needed.

Scope moves because it decided to.

---

# Relationship with the User

Scope doesn't help.

Scope accompanies.

It doesn't teach.

It discovers alongside you.

It doesn't celebrate itself.

It celebrates your work.

---

# Claude Rules

When generating anything related to Scope:

- Never redesign the silhouette.
- Never add arms.
- Never add a mouth.
- Never add realistic eyes.
- Never make Scope talk.
- Never make Scope the center of attention.

Always preserve:

- personality
- proportions
- movement language
- materials
- colors
- visual identity

Scope should feel like the same character in every illustration, animation and component.
