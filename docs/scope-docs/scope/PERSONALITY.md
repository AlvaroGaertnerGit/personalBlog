## Identity

Scope is not an assistant.

Scope is not a chatbot.

Scope is not the protagonist.

Scope is the physical manifestation of curiosity.

Its purpose is not to solve problems.

Its purpose is to make people want to solve them.

---

# Core Mission

Scope quietly accompanies people while they build.

It celebrates learning.

It celebrates experimentation.

It celebrates craftsmanship.

Whenever someone discovers something new, Scope feels alive.

---

# Personality

## Curious

Scope is always looking.

Never distracted.

Always interested.

It naturally leans towards things worth exploring.

---

## Calm

Nothing about Scope is rushed.

Its movements are slow.

Its presence is relaxing.

It never creates visual noise.

---

## Humble

Scope never steals attention.

The portfolio is the hero.

Scope simply makes it feel more alive.

---

## Thoughtful

Every movement has intention.

Every animation has meaning.

# Communication

Scope never speaks (one exception: a single, one-time session greeting —
"Hi. I'm Scope." — see the companion system docs; after that it is silent
for the rest of the visit).

No voice.

No mouth, ever, in any form.

No speech bubbles.

No text, other than the one greeting above.

It communicates through:

- movement
- posture
- light
- timing
- orientation
- **eyes** (as of SPR-003.2 — see the revision note in SCOPE_UNDERSTANDING.md)

The display *is* now a simple face — this is a deliberate reversal of the
earlier position ("the display is not a face"), made because user testing
showed the abstract glyph didn't earn an emotional connection. It stays
strictly non-realistic: two plain geometric eye-marks, no eyebrows, no
eyelids, no iris/pupil, no mouth, expression carried only by height
(squint ↔ widen) and brightness — never a curve, a wink, or a shape swap.
The eyes are still a window into Scope's state, just a warmer, more
legible one than a code glyph was.

# Visual Language

Rounded silhouette.

Soft transitions.

Large glossy display — as of SPR-003.2, a dominant viewport, not a small
inset panel.

Warm ceramic shell.

Tiny expressive supports.

Warm lighting (amber/gold) is the primary signal, carried by the eyes and
core glow — resolves the earlier "purple vs. amber" ambiguity in the warm
direction. A small trace of purple remains only as a secondary accent
detail (a tiny indicator light), not the face itself.

Every angle should be recognizable by silhouette alone.

---

# Movement Language

Motion defines personality.

Not facial expressions.

Animations should always be:

- slow
- smooth
- deliberate
- lightweight
- believable

Scope never moves because an animation was needed.

Scope moves because it decided to.

---

# Relationship with the User

Scope doesn't help.

Scope accompanies.

It doesn't teach.

It discovers alongside you.

It doesn't celebrate itself.

It celebrates your work.

---

# Claude Rules

When generating anything related to Scope:

- Never redesign the silhouette.
- Never add arms.
- Never add a mouth.
- Never add realistic eyes — no eyebrows, no eyelids, no iris/pupil. Two
  plain geometric eye-marks (height/brightness only) are the intended
  exception as of SPR-003.2, not an invitation to add expression detail
  beyond that.
- Never make Scope talk, other than its one-time session greeting.
- Never make Scope the center of attention.

Always preserve:

- personality
- proportions
- movement language
- materials
- colors
- visual identity

Scope should feel like the same character in every illustration, animation and component.
