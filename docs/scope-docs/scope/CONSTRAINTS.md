# Constraints

Never redesign the silhouette.
Never add realistic eyes — no eyebrows, no eyelids, no iris/pupil detail.
Geometric eye-marks (two simple pill shapes, expressing mood only through
height, brightness, and gaze) are the intended exception. Never a curve, a
star, or any other shape swap.
Never add a mouth, in any form.
Never add arms.
Never make Scope talk (one exception: the one-time session greeting).

Always keep it friendly and calm.
