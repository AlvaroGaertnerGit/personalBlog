# Scope Visual Language

Version 2.0

---

# Overall Shape

Scope is composed almost entirely of rounded geometry.

No sharp edges.

No mechanical joints.

No exposed technology.

No visible complexity.

The silhouette should feel sculpted rather than assembled.

---

# Body

Large rounded shell.

Almost spherical.

Slightly flattened at the bottom.

Minimal details.

Tiny feet.

Tiny antenna.

The antenna is intentionally simple.

It is not technology.

It behaves almost like an insect antenna.

A subtle indicator of attention.

---

# Face

The face is the defining element.

It occupies approximately 70% of the visible front.

Rounded rectangle.

Large corner radius.

Glossy black surface.

Deep black.

Almost mirror-like.

---

# Eyes

The eyes define Scope.

Everything else is secondary.

Two vertical rounded capsules.

Warm amber.

Soft bloom.

High contrast.

Never perfectly static.

Very subtle micro motion.

Very subtle depth.

They should feel like tiny sources of life.

Never LEDs.

Never screens.

Never pixels.

They are eyes.

---

# Materials

Soft ceramic shell.

Matte finish.

Glossy face.

Warm indirect lighting.

Minimal reflections.

Premium product finish.

Think industrial design.

Not illustration.

---

# Colors

Primary shell:

Warm ivory.

Face:

Deep black.

Eyes:

Warm amber.

Accent:

Extremely subtle atmospheric purple only when interacting with the environment.

The eyes should never become blue.

The warmth of the eyes is what creates emotional connection.

---

# Antenna

Tiny.

Elegant.

Flexible.

Never exaggerated.

It should subtly react to movement.

Almost like a living creature.

Never like a radio antenna.

---

# Feet

Tiny.

Rounded.

Minimal.

They make Scope feel grounded.

Never mechanical.

Never articulated.

---

# Motion

Movement starts slowly.

Movement ends slowly.

Nothing snaps.

Nothing feels robotic.

Weight is always perceptible.

Every motion slightly overlaps another.

Tiny secondary motion is encouraged.

---

# Breathing

Breathing is always active.

Very slow.

Very soft.

Almost imperceptible.

It should feel like life rather than animation.

---

# Eye Behaviour

Eyes are Scope's primary language.

Allowed behaviours:

- Blink
- Double blink
- Slow blink
- Tiny squint
- Curiosity widening
- Focus
- Looking left
- Looking right
- Looking up
- Looking down
- Micro saccades
- Slight eye convergence
- Relaxed neutral

Never exaggerate.

Never become cartoon eyes.

Never use stars, hearts, crosses or emoji-like shapes.

Expression comes only from movement, timing and spacing.

---

# Idle Behaviour

Every 8–15 seconds of inactivity, Scope should perform one noticeable but elegant behaviour.

Examples:

- A slow blink.
- A double blink followed by a tiny head tilt.
- Looking briefly around the environment.
- Looking at the cursor's last known position.
- A tiny stretch followed by an exhale.
- A small bounce before settling.
- Eyes briefly widening after "noticing" something.
- Antenna gently flexing before returning to neutral.

Behaviours should not repeat predictably.

Each idle action should tell a tiny story.

The visitor should gradually believe Scope has its own thoughts.

---

# Design Test

Remove every animation.

Does Scope still look alive?

If not...

The design is wrong.

Add the animations back.

Does Scope now feel like a tiny living companion rather than an animated object?

If yes...

The design is correct.
