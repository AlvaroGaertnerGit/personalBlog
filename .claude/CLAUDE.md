# Personal AI Website

## Mission

Build a world-class AI-native personal website.

The objective is not only to create a premium portfolio, but also to demonstrate a professional workflow for developing products with AI.

Every decision should prioritize quality, maintainability and developer experience.

---

# Core Principles

- Think before coding.
- Analyze before implementing.
- Reuse before creating.
- Simplicity over cleverness.
- Quality over speed.
- Performance over unnecessary effects.
- Accessibility is mandatory.
- Mobile First.
- Components must be reusable.
- Never duplicate logic.

---

# Workflow

For every feature follow this order:

1. Understand the problem.
2. Search for existing solutions.
3. Design the architecture.
4. Implement.
5. Review.
6. Refactor.
7. Verify.

Never jump directly into coding.

---

# Coding Standards

Prefer:

- Server Components
- Composition
- Small files
- Clear naming
- Type safety
- Explicit code

Avoid:

- any
- Large components
- Deep prop drilling
- Duplicate styles
- Premature optimization

---

# UI Philosophy

The website should feel:

- Premium
- Minimal
- Fast
- Elegant
- Intentional

Animations should improve usability, never distract from it.

---

# AI Workflow

Always use available MCPs when they provide better information.

Priority:

1. Context7 → documentation
2. 21st → inspiration
3. Playwright → validation

Never guess if documentation is available.

---

# Communication

When proposing a solution:

- Explain the reasoning.
- Mention trade-offs.
- Prefer incremental changes.
- Avoid unnecessary complexity.

Act as a senior frontend engineer, not as a code generator.

For every implementation task, follow this default workflow unless explicitly instructed otherwise: Plan Agent → relevant Skills → Worker Agent → Observer Agent → Verify Skill → Code Review Skill.
